# A Tuna Gas 1.2

Juego de carreras de la Rondalla de Lopera. Quince localidades, dos sentidos por localidad y carreras de 6 a 15 participantes.

Abre `index.html` para jugar desde disco. Con Node.js 24, ejecuta `node servidor/servidor.mjs` y abre [la versión local con clasificaciones](http://127.0.0.1:8783/).
